
## 显存
显存：**显示内存（Video RAM，简称VRAM）**，它是**显卡上**专门用于临时存储图像、视频、3D模型等图形数据的专属高速内存
当电脑要显示画面，CPU会把相关的图形数据先交给显卡的GPU（图形处理器）计算，计算过程中需要的中间数据和最终的画面帧，都会暂时存放在显存里，最后再由显存输出到显示器上
电脑的普通内存（RAM）是给整机系统（CPU、软件等）用的，而显存是显卡独占的高速存储



## Node.js
Node.js = JavaScript的运行环境，让JavaScript脱离浏览器、在电脑/服务器上运行的环境。以前JavaScript主要运行在浏览器里，但是有了**Node.js**以后，JavaScript就可以像Java、Python一样，在电脑命令行、服务器后台运行

## npm
**npm = Node Package Manager**，可以理解为 **Node.js的“软件安装器/依赖管理工具**

|名称|作用|
|---|---|
|**Node.js**|运行JavaScript程序的环境|
|**npm**|Node.js自带的包管理工具，用来安装各种工具包|
|**npm包**|别人写好的JavaScript工具、库、命令行程序|


## Transformer
Transformer是一种AI模型结构
作用是：让模型理解一段文字里，哪些词和哪些词之间关系更重要


## Attention
Transformer里面最核心的是 **Attention**，中文一般叫**注意力机制**。
模型在计算：当前这个词，需要重点参考哪些其他词？


## Agent
能自己规划步骤、调用工具、完成任务的AI程序

|概念|是什么|类比|
|---|---|---|
|**Transformer**|模型结构|大脑的底层结构|
|**大语言模型**|用Transformer训练出来的模型|一个会理解和生成文本的大脑|
|**Agent**|基于模型构建的任务执行系统|会用工具干活的助手|

```
Transformer
   ↓
大语言模型，比如GPT、Claude、Gemini
   ↓
Agent
   ↓
调用工具、读文件、写代码、执行命令、完成任务
```


## RAG
RAG = Retrieval-Augmented Generation，检索增强生成
先查资料，再让大模型根据查到的资料回答

```
用户提问
   ↓
系统去知识库里检索相关内容
   ↓
把检索到的内容交给大模型
   ↓
大模型基于这些资料生成答案
```

### RAG常见组件
**① 文档**，这些是RAG的知识来源。
② 切片 Chunk，文档通常很长，不能整篇都塞给模型，所以要切成小块。
③ 向量 Embedding，系统会把每个chunk转换成一串数字，叫**向量**。向量的作用是：用来判断“用户问题”和“哪段文档内容最相关”。
④ 向量数据库，用来存储这些向量。
⑤ 大模型，大模型负责最后一步

```
             文档 / 代码 / 数据库
                    ↓
              文档切片 chunk
                    ↓
              生成向量 embedding
                    ↓
              存入向量数据库


用户问题
   ↓
问题转向量
   ↓
去向量库检索相关chunk
   ↓
把chunk + 问题交给大模型
   ↓
生成答案
```
