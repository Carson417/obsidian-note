# 入门
## JDK下载
JDK：java development kit，java开发工具包
## 环境变量
step1：复制文件路径
step2：保存到环境变量中
作用：在任意位置，都可以打开配置后的文件

配置jdk
step1：配置 JAVA_HOME，JDK安装路径：D:\develop\JDK
step2：配置 PATH，Java.exe程序的路径，加\bin，`%JAVA_HOME%\bin`
- % 是引用，但是win10有bug，可能重启会失效

# 语法篇
字面量：程序中的数据
变量：程序中用来存储单个数据的容器，是一个空间
- 变量在使用前一定要进行赋值
- 一条语句可以定义多个变量，也可以连续赋值（shoa'y）
数据类型：为空间中存储的数据，加入类型限制
